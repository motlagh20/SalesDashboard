# برنامه پیاده‌سازی سرویس ایمیل، ارسال اعلان‌ها و بازیابی دوگانه رمز عبور (ایمیل / پیامک)

این سند طرح فنی و اجرایی کامل برای راه‌اندازی سرویس ایمیل در سامانه صنایع سفال طبرستان را ارائه می‌دهد. این راهکار به ادمین امکان پیکربندی همزمان پروتکل استاندارد SMTP و سرویس‌های Webhook/API ابری را داده، ابزار تست و عیب‌یابی ارسال ایمیل را در پنل مدیریت فراهم می‌کند و در صفحه بازیابی رمز عبور، انتخاب بین دریافت کد از طریق پیامک (SMS OTP) و ایمیل را در اختیار کاربران قرار می‌دهد.

---

## ۱. اهداف و مشخصات نیازمندی‌ها
1. **پشتیبانی دوگانه از ارائه‌دهندگان ایمیل:**
   - **پروتکل SMTP استاندارد:** اتصال به سرورهای ایمیل سازمانی، Gmail ،Outlook و سایر میل‌سرورها با تنظیمات Host, Port, Secure (SSL/TLS), Username, Password.
   - **سرویس‌های Webhook / REST API:** ارسال ایمیل از طریق ارائه‌دهندگان ابری (مانند Resend، SendGrid، سرویس‌های ایمیل وب‌سرویسی ایرانی) با URL و API Key.
2. **ابزار تست و عیب‌یابی ارتباط در پنل ادمین:**
   - دکمه تست آنلاین ارسال ایمیل آزمایشی با نمایش وضعیت اتصال (Connection Diagnostics)، لاگ خطای دقیق و تایید سلامت ارسال.
3. **انتخاب دوگانه کاربر در صفحه ورود/فراموشی رمز عبور:**
   - کاربر در صفحه «فراموشی رمز عبور» می‌تواند بین دو گزینه:
     - 📱 **ارسال کد تایید به شماره همراه (SMS OTP)**
     - ✉️ **ارسال کد تایید به ایمیل حساب کاربری (Email OTP)**
     انتخاب کند.
4. **امنیت داده‌ها و اطلاعات حساس:**
   - ماسک کردن کلمه عبور SMTP و API Key در زمان نمایش در رابط کاربری جهت جلوگیری از افشای اطلاعات.
   - اعمال محدودیت نرخ درخواست (Rate Limiting) و انقضای ۵ دقیقه‌ای کدهای یکبارمصرف ایمیلی.

## ۲. معماری ماژول‌ها و تغییرات فایل‌ها

### الف) ماژول بک‌اند ایمیل (`server/email.ts`)
ایجاد ماژول اختصاصی و استاندارد برای مدیریت و ارسال ایمیل‌ها:
- تابع `sendEmail({ to, subject, html, text })`: دریافت پارامترهای ایمیل و ارسال هوشمند از طریق پروتکل فعال (SMTP یا API Webhook).
- تابع `testEmailConnection(config, targetEmail)`: بررسی برقراری ارتباط (Handshake) و ارسال پیام آزمایشی تشخیصی.
- قالب‌های ایمیل شکیل و سازگار با زبان فارسی (RTL، آرم طبرستان، دکمه‌های واضح و متن خوانا برای کد OTP و اعلان‌ها).

### ب) اندپوینت‌های API در سرور (`server.ts`)
1. `GET /api/system/email-settings` (احراز هویت شده، فقط ادمین): دریافت تنظیمات جاری سرویس ایمیل (با پسورد/کلید ماسک‌شده).
2. `PUT /api/system/email-settings` (فقط ادمین): ذخیره و به‌روزرسانی تنظیمات سرور ایمیل و کانال‌های مجاز بازیابی.
3. `POST /api/system/email-settings/test` (فقط ادمین): ارسال ایمیل تست به آدرس مشخص‌شده جهت سنجش اتصال و نمایش گزارش عیب‌یابی.
4. `POST /api/auth/forgot-password/request-email-otp`: صدور و ارسال کد ۶ رقمی اعتبارسنجی به ایمیل کاربر.
5. `POST /api/auth/forgot-password/verify-email-otp`: بررسی صحت کد دریافتی و صدور توکن مجاز جهت تنظیم رمز عبور جدید.

### ج) تب جدید در پنل مدیریت (`BaseDefinitionsDashboard.tsx` یا پنل سیستم)
افزودن تب **«تنظیمات سرویس ایمیل و اطلاع‌رسانی»**:
- انتخاب نوع ارائه‌دهنده: سوییچ بین `SMTP سازمانی` و `Webhook / API ابری`.
- فرم پیکربندی SMTP (آدرس سرور، درگاه، پروتکل امنیتی TLS/SSL، نام کاربری، رمز عبور).
- فرم پیکربندی Webhook/API (آدرس اندپوینت، کلید دسترسی / Bearer Token).
- فیلدهای عمومی: نام فرستنده پیش‌فرض (مثلاً *«صنایع سفال طبرستان»*) و ایمیل فرستنده (`sender@domain.com`).
- بخش «تست سلامت و ارسال آزمایشی» با ورودی ایمیل مقصد، دکمه ارسال، و جعبه نمایش لاگ تشخیصی زنده.
- سوییچ فعال‌سازی «امکان بازیابی رمز از طریق ایمیل برای کاربران».

### د) به‌روزرسانی فرم ورود و فراموشی رمز عبور (`LoginGate.tsx`)
- افزودن تب تعاملی انتخاب روش بازیابی:
  - `پیامک به شماره همراه (SMS)`
  - `ارسال به پست الکترونیکی (Email)`
- در صورت انتخاب ایمیل: کاربر نام کاربری یا ایمیل خود را وارد کرده، کد تایید را در ایمیل دریافت می‌کند و رمز جدید را ثبت می‌نماید.
- افزودن فیلد اختیاری «آدرس ایمیل» در فرم تعریف و ویرایش کاربران در تب کاربران.

## ۳. مراحل گام‌به‌گام پیاده‌سازی

1. **نصب پکیج‌های مورد نیاز:**
   - نصب پکیج `nodemailer` و `@types/nodemailer` جهت برقراری ارتباط پایدار با سرورهای SMTP.
2. **پیاده‌سازی هسته سرویس ایمیل (`server/email.ts`):**
   - پیاده‌سازی سرویس‌دهنده SMTP با Nodemailer و سرویس‌دهنده Webhook/API با Native Fetch.
   - طراحی قالب HTML واکنش‌گرا و فارسی برای کد تایید و پیام‌های آزمایشی.
3. **پیاده‌سازی اندپوینت‌های API در `server.ts`:**
   - پیاده‌سازی متدهای ذخیره تنظیمات، تست اتصال، صدور کد و بازنشانی رمز با ایمیل.
4. **توسعه رابط کاربری پیکربندی ایمیل در تب تنظیمات ادمین:**
   - طراحی فرم شکیل همراه با اعتبارسنجی ورودی‌ها، راهنمای پروتکل‌ها و بخش تست زنده ارتباط.
5. **به‌روزرسانی صفحه فراموشی رمز عبور در `LoginGate.tsx`:**
   - افزودن امکان انتخاب کاربر بین پیامک و ایمیل با تجربه کاربری روان و راهنمایی‌های فارسی.
6. **تست و ارزیابی نهایی:**
   - اجرای تست‌های بیلد، لینتر و اجرای آزمایشی اندپوینت‌های تست ایمیل و بازنشانی رمز عبور.
